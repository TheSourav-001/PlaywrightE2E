# Playwright Automation Suite

A Playwright-based end-to-end automation suite for the `demo.evershop.io` e-commerce site. This repository implements a Page Object Model (POM) architecture and includes functional coverage for account registration, login, product search, cart behavior, checkout flow, order success validations, and logout.

## Key Features

- Playwright test runner with `@playwright/test`
- Page Object Model architecture for reusable page actions
- Authentication setup project with browser storage state reuse
- Cross-browser configuration for Chromium, Firefox, and WebKit
- Built-in HTML and Allure reporting
- Test data separated into reusable fixture files

## Test Coverage

### Account Flow
- Registration with valid credentials
- Validation of missing full name, email, password
- Invalid email formatting and duplicate account handling
- Password minimum length validation
- Show/hide password toggle behavior
- Login with correct credentials
- Login error handling for invalid or missing credentials
- Login stability and form visibility after failure

### E-commerce Journey
- Product search from the homepage
- Product details validation (name, price, SKU, description, options)
- Add to cart and cart page verification
- Cart persistence and checkout navigation
- Complete checkout flow with shipping and payment selection
- Order success page verification (order number, totals, contact info)
- Logout flow and account access restrictions after logout

### Data Driven Elements
- `data/products.js` contains product names and URLs used in search and product flow testing
- `data/checkoutData.js` contains shipping details and address metadata used during checkout

## Setup

1. Install dependencies:

```bash
npm install
```

2. Install Playwright browsers if required:

```bash
npx playwright install
```

## Run Tests

Execute the full suite:

```bash
npm test
```

Run a specific test file:

```bash
npx playwright test tests/Account/login.spec.js
```

Run Playwright with debug mode:

```bash
npx playwright test --debug
```

## Reporting

This project is configured with the following reporters in `playwright.config.js`:
- `html`
- `list`
- `allure-playwright`

### Allure Report

Allure results are written to `allure-results/`. To generate or refresh the HTML report, use:

```bash
npx allure generate allure-results --clean -o allure-report
```

Then open the report:

```bash
npx allure open allure-report
```

> Note: The `allure` CLI must be installed on your machine or available in your environment.

## Notes

- `playwright.config.js` uses `baseURL: 'https://demo.evershop.io/'`, so most tests navigate with relative paths.
- The `setup` project authenticates using `tests/setup/auth.setup.js` and stores authentication state in `playwright/.auth/user.json`.
- Screenshots, videos, and traces are configured to capture failures for debugging.
- The root `README.md` was updated to document the project structure and usage clearly.
